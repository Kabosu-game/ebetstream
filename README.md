# Ebetstream Web

Application web principale d'Ebetstream (Vue + API Laravel) pour le streaming competitif, les interactions communautaires et la gestion des fonctionnalites produit.

---

## Documentation officielle

- Presentation generale : `PRESENTATION_GENERALE_EBETSTREAM.md`
- Concept produit arena : `EBETSTREAM_ARENA_DOCUMENT.md`
- Programme officiel de monetisation : `PROGRAMME_OFFICIEL_MONETISATION_EBETSTREAM.md`

## Demarrage rapide

```bash
npm install
npm run dev
```
