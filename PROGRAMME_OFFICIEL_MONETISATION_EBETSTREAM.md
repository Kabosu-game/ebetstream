## 1) Vision

Ebetstream est une plateforme de streaming competitif permettant aux gamers de generer des revenus grace a :
- leur performance
- leur influence
- l'engagement de leur audience

La plateforme cree une nouvelle economie ou le skill devient un actif monetisable.

## 2) Sources de revenus des streamers

### A. Donations directes

Les spectateurs peuvent envoyer des donations en direct.

Repartition :
- 85 % pour le streamer
- 15 % pour la plateforme

### B. Support Prediction System (Credits Ebetstream)

Les spectateurs utilisent des credits pour soutenir un streamer lors de matchs competitifs.

Ebetstream preleve une commission sur les credits utilises.

Repartition de la commission :
- 40 % pour le streamer
- 60 % pour la plateforme

### C. Matchs sponsorises

Ebetstream organise des defis sponsorises et des tournois.

Repartition :
- 60 % prize pool joueurs
- 20 % streamer organisateur
- 20 % plateforme

## 3) Niveaux des streamers

- Rookie : 0 a 1 000 followers, commission 30 %
- Pro : 1 000 a 10 000 followers, commission 40 %
- Elite : plus de 10 000 followers, commission 50 %, badge verifie et promotion interne

## 4) Regles et securite

- Verification d'identite obligatoire

- Transparence totale

## 7) Objectif du reseau Agent

Creer un reseau d'agents officiels EBETSTREAM capables de :
- recharger leur compte via crypto
- effectuer des depots internes
- gerer les retraits
- garantir securite et tracabilite
- reduire le risque pour la plateforme

## 8) Concept : Agent Crypto EBETSTREAM

### Definition

Un Agent EBETSTREAM est un partenaire certifie disposant d'un compte special "Agent", capable de recharger son solde via crypto et d'effectuer des transactions internes pour les utilisateurs.

## 9) Structure du systeme

### A. Creation du compte Agent

Conditions :
- verification d'identite (KYC)
- signature d'un contrat digital
- connaissance minimale en crypto
- depot de garantie minimum

Apres validation, l'agent obtient :
- un compte "Agent"
- un solde Agent distinct
- un acces au tableau de bord Agent

## 10) Comment fonctionne le depot

### Etape 1 : l'agent recharge son compte

L'agent :
1. envoie de la crypto (USDT recommande) vers le wallet officiel EBETSTREAM
2. la plateforme credite son compte Agent
3. son solde interne est mis a jour

Exemple :
- Agent envoie 1 000 USDT
- son compte Agent affiche 1 000 USD disponibles

### Etape 2 : depot d'un joueur

Le joueur a deux options :

#### Option A - Depot crypto direct
- Le joueur envoie la crypto a EBETSTREAM
- Credit automatique

#### Option B - Depot via Agent
1. Le joueur donne l'argent a l'agent (cash ou mobile money)
2. L'agent fait un transfert interne depuis son solde Agent vers le compte du joueur
3. Le solde Agent diminue
4. Le solde joueur augmente

Exemple :
- Solde Agent : 1 000 USD
- Depot joueur : 100 USD
- Nouveau solde Agent : 900 USD

## 11) Comment fonctionne le retrait

Le joueur a deux choix :

### Option A - Retrait crypto
- Le joueur demande un retrait crypto
- EBETSTREAM envoie la crypto vers son wallet

### Option B - Retrait via Agent
1. Le joueur selectionne "Retrait via Agent"
2. Il choisit un agent disponible
3. Le systeme bloque le montant
4. L'agent remet l'argent physiquement
5. L'agent valide la transaction
6. Le montant est debite du compte Agent

## 12) Transparence et securite

Pour garantir un systeme solide, integrer :

### Historique complet des transactions
- chaque transfert est enregistre
- tracabilite totale

### Solde separe
- compte principal joueur
- compte bonus
- compte Agent distinct

### Limites journalieres
- limite depot
- limite retrait
- limite transfert interne

### Systeme de notation Agent
- les joueurs peuvent noter l'agent

## 13) Modele economique Agent

L'agent gagne :
- commission sur chaque depot
- commission sur chaque retrait
- bonus volume mensuel

Exemple :
- 2 % sur depots
- 1.5 % sur retraits

Plus l'agent travaille, plus il gagne.

## 14) Pourquoi ce systeme est meilleur

Avant :
- agents non structures
- risque de fraude
- pas de controle clair

Apres :
- agents certifies
- recharge uniquement via crypto
- tracabilite interne
- solde prepaye (pas de dette)

Regle critique :
L'agent ne peut jamais transferer plus que son solde.
Donc pas de risque de perte directe pour EBETSTREAM.

## 15) Avantages strategiques

- expansion rapide dans plusieurs villes
- systeme scalable international
- reduction du cash handling par la plateforme
- securisation via crypto
- meilleur controle des flux

## 16) Points a bien cadrer

2. definir un minimum de recharge Agent
3. exiger un depot de garantie
4. mettre en place un systeme anti-blanchiment (AML)
5. creer un contrat juridique clair
